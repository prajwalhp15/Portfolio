## 🎨 Visual Design & Art Direction

- **Style**: Premium 2D Creative Editorial Portfolio.

## 🛠️ Technology Stack

- **Core**: React 18, TypeScript, Vite
- **Styling**: Tailwind CSS, Vanilla CSS design tokens (`#F3F0E8`, `#161616`, `#FF4D24`)
- **Animation**: Framer Motion (subtle reveals, minimal micro-interactions)
- **Icons**: Lucide React
- **Data Layer**: Centralized content store in `src/data/portfolioData.ts`
